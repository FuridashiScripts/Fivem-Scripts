Search trash containers across Los Santos and discover random loot! This lightweight ESX script adds an immersive dumpster-diving system to your FiveM roleplay server.

---

## ✨ Features

- 🗑️ Search dumpsters and trash bins
- 🎲 Random reward system
- ⏳ Search cooldown
- 📦 Fully configurable loot table
- 🚓 Perfect for RP and survival gameplay
- ⚡ Optimized (low resmon usage)
- 🔧 Easy configuration
- 🌍 ESX Compatible

## ⚙️ Installation

1. Download the latest release.
2. Extract the folder into your `resources` directory.
3. Add the following line to your `server.cfg`:

```cfg
ensure Furidashi-TrashSearcher
```

4. Configure the script to your liking.
5. Restart your server.

---

## ⚙️ Configuration

Everything can be configured inside:

```
config.lua
```

You can customize:

- Loot items
- Loot chances
- Search cooldown
- Search locations
- Notifications
- Progress duration
